# SafeSync

**Gemini-powered emergency triage and dispatch for hotels and resorts.**

Built by **Team CrisisCore** for the **Google Solution Challenge 2026**  
Challenge: *Rapid Crisis Response in Hospitality*

SafeSync is a real-time crisis command system designed to help hospitality staff report emergencies in plain, even panicked, language. Gemini classifies the incident, scores its severity from 0 to 100, extracts the location and recommends responders.

The system then presents a crisis-specific action protocol and records the incident on a live command board with an incident timeline and map.

## Key Features

- Natural-language emergency reporting
- Gemini-powered incident classification
- Severity scoring from 0 to 100
- Location extraction and responder recommendations
- Crisis-specific action protocols
- Live command board with incident timeline and map
- Fail-safe fallback for situations where AI assistance is unavailable

## Tech Stack

- Python
- Flask
- Google Gemini API
- MongoDB Atlas
- Leaflet.js
- Render
